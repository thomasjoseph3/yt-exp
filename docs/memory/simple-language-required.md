The owner watched video #2 ("Recursive Self-Improvement in AI") and could not understand it: "we need to use simple language that even a 10th student can understand... explain with an example and if it is core topic explain technically but everyone should understand it".

**Why:** If the owner can't follow a video, the audience won't either; retention and the 10k-subscriber goal depend on it. Short sentences alone don't fix it (#2 scored as "easy" on reading-level formulas); the problem was abstract ideas with no concrete example and too-advanced topics.
**How to apply:** Rules live in thoma/character.md ("10th-standard test", one running example, example-first-then-name, max 2 terms per Short) and the review's "student test" in writer.REVIEW_SYSTEM. When the owner flags confusing content, tighten those, not a readability formula. Related: [[thoma-channel-project]], [[natural-voice-required]].

**Refined 2026-10-27:** "understandable by everyone with simple examples... not every time but if it is necessary". Abstract how-it-works ideas get a simple everyday example; concrete topics (a real tool, real news, a how-to) use the real thing as the example, no forced invented one. Code gates now enforce: every jargon word/acronym listed in script "terms" and explained where first said (writer._term_problems), and on-screen labels must be spoken (writer._label_problems).
